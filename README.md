# Student Portfolio

A responsive, multi-page student portfolio built with React, Vite, React Router, and Lucide icons. Pages are available at `/`, `/about`, `/projects`, and `/contact`.

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL in the terminal. Create a production build with `npm run build`.

## Make it yours

Update the Gopal krishnareddy Maram, school, Btech Graduated (2025), email, social links, and project details in `src/App.jsx`. Set `contactEmail` to the inbox that should receive form submissions. The contact form uses FormSubmit; confirm its activation email after the first real submission before expecting further messages. Replace each project&apos;s `href` with its live demo or GitHub URL. Replace the Unsplash image URLs with your own project screenshots. Adjust the palette, typography, and responsive styles in `src/styles.css`. The font is loaded from Google Fonts.
